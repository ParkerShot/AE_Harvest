# AE Harvest — риг сбора ресурсов для After Effects

Панель для After Effects: монеты летят по дуге из точки-эмиттера в бар ресурса (или из бара наружу при трате), вокруг бара вспыхивает размытый светящийся контур — зелёный на сборе, красный на трате, — счётчик тикает.

Главное: **вся геометрия на выражениях**. Меняете размер композиции (1920×1920 → 1080×1920 → 1080×1350) — бар сам примагничивается к своему углу, точка прилёта едет за баром, точка вылета — за своим якорем. Руками ничего не двигаете.

## Установка

Скопировать `AE_Harvest_Panel.jsx` в папку скриптов AE:

```
C:\Program Files\Adobe\Adobe After Effects <версия>\Support Files\Scripts\ScriptUI Panels\
```

(нужны права администратора), затем перезапустить AE → `Window → AE_Harvest_Panel.jsx`.

Без установки: `File → Scripts → Run Script File...` — панель откроется плавающим окном.

> AE читает скрипты **при запуске**. После обновления файла — перезапуск.

## Сборка рига

Кнопки по порядку:

1. **Create / update controller** — создаёт два нулла: `AEH_CTRL` (повседневные ручки) и `AEH_SETUP` (настройка «один раз и забыл»; shy + guide, спрятан). Повторный клик безопасен: добавляет только недостающее, ваши значения не трогает.
2. Выделить слой бара → **Selected layer → BAR**. Слой станет `AEH_BAR`, получит магнит-позицию и пульс. Появятся `AEH_EMIT` (точка A), `AEH_COLLECT` (точка B, приклеена к бару) и `AEH_GLOW` (светящийся контур).
3. Выделить слой монеты → **Selected layer → coins**. Оригинал спрячется как `AEH_COIN_SRC`, появятся дубли `AEH_COIN_1..N`. Поменяли `Coins` — нажать ещё раз.
4. **Create NEW counter text** — новый текст-счётчик, припарентен к бару.
5. **Link SELECTED text → counter** — если счётчик уже есть и стилизован (иконка, шрифт, фон): выделите его текстовый слой и нажмите. Вид сохранится, изменится только источник числа; текущее число подхватится как `Base Value`. Работает и когда текст лежит во вложенном прекомпе.

## Как заменить монетку на другой ассет

**Кнопка `Replace coin artwork...`** — нажали, выбрали файл (PNG / PSD / AI / любой футаж), всё. Скрипт сам импортирует его, положит в композицию, подставит вместо старой монеты и пересоберёт рой монет с выражениями. Выделять и настраивать ничего не нужно.

Размер правится слайдером `Coin Scale` на `AEH_CTRL`.

## Запуск полётов — маркеры

Каждый маркер на `AEH_CTRL` = один залп. Комментарий маркера — сумма:

- `+100` (или `100`) — **сбор**: монеты летят A → бар, контур зелёный, счётчик +100;
- `-50` — **трата**: монеты летят бар → A, контур красный, счётчик −50.

Кнопки `+ GAIN` / `− SPEND` ставят маркер на текущем времени и спрашивают сумму. Пустой комментарий = `Value per Burst`.

Счётчик прибавляет по частям — по монете за прилёт (при трате списывает в момент вылета).

## Параметры на AEH_CTRL (повседневные)

| Контрол | Что делает |
|---|---|
| Flight Time | длительность полёта монеты, сек (= скорость) |
| Arc Height | высота дуги; минус — выгнуть в другую сторону |
| Grow % | на скольких % пути монета вырастает из нуля (и гаснет в конце) |
| Coin Scale | максимальный масштаб монеты |
| Align Rotation | поворачивать монету по касательной к дуге |
| Pulse Amount / Pulse Time | сила и длительность пульса бара |
| Glow Width | толщина светящегося кольца |
| Glow Roundness | внешнее скругление кольца |
| Glow Inner Roundness | внутреннее скругление кольца |
| Glow Radius | размытие свечения |
| Glow Fit (X,Y) | подгонка размера кольца; **минус = плотнее к бару** |
| Glow Shift (X,Y) | сдвиг кольца (если бокс несимметричен из-за иконки) |
| Glow Base | постоянное свечение, 0..100 |
| Flash Amount | сила вспышки в момент сбора/траты |
| Gain / Spend Color | цвета сбора и траты |
| Base Value | стартовое значение счётчика |
| Value per Burst | сумма по умолчанию, если у маркера нет числа |

## Точка вылета — свободная

`AEH_EMIT` — обычный нулл **без выражений**: таскайте мышкой, ставьте кейфреймы, анимируйте. Скрытый родитель `AEH_EMIT_ANCHOR` держит привязку к композиции, чтобы точка не уехала при ресайзе; трогать его не нужно.

## Параметры на AEH_SETUP (настроил и забыл)

Нулл `AEH_SETUP` — shy. Чтобы добраться: включите переключатель **Shy** в шапке таймлайна.

Якоря — **слайдеры 1..9** (сетка 3×3 слева направо: 1 — верх-лево, 5 — центр, 9 — низ-право). Дропдаунов нет намеренно: их `setPropertyParameters` молча ломается на части сборок AE.

| Контрол | Что делает |
|---|---|
| Bar Anchor (1..9) | магнит бара: угол / край / центр композиции |
| Bar Offset (X,Y) | сдвиг бара **внутрь** от прижатого положения (для любого угла) |
| Emitter Anchor (1..9) + Emitter Offset | к чему привязана точка A при ресайзе |
| Collect Anchor (1..9) + Collect Offset | магнит точки прилёта по боксу бара (`4` — в иконку слева) + сдвиг |
| Coins | монет в залпе (после смены — пересобрать шаг 3) |

## Пресеты

**Save current as defaults** — читает текущие значения с `AEH_CTRL` / `AEH_SETUP` и пишет их в `AE_Harvest_defaults.json` рядом с преференсами AE. Дальше новые риги строятся с вашими значениями. Права администратора не нужны.

> Файл локальный: вместе с `.jsx` он не передаётся. Чтобы дефолты уехали к другому человеку, их надо вписать в блок `DEFAULTS` в начале скрипта.

## Ресайз композиции

Меняете размер — бар примагничивается к якорю с теми же отступами, точка B следует за баром, точка A — за своим якорем. Кольцо тянется по боксу бара.

## Ограничения

- Слои рига не переименовывать: выражения ссылаются на имена `AEH_*`.
- Слои должны быть 2D, без разделённых измерений Position.
- `AEH_EMIT` парентится к `AEH_EMIT_ANCHOR`, поэтому его `transform.position` — координата относительно родителя. В выражениях точки читаются через `toComp()`.
- Шлейф монет считается автоматически из `Flight Time` и `Coins` — отдельной ручки нет.
- Кольцо строится по **боксу** бара. Если бар — прекомп, бокс покрывает всё его содержимое (торчащая иконка расширяет его) — подгоняется через `Glow Fit` / `Glow Shift`.
- Дропдауны требуют AE 17.0.1+ (2020); на старее — слайдеры 1–9 в том же порядке якорей.
